# Loading Indicator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** While the provider runs, `how-to` shows `<frame> thinking <n>s` on stderr (frames `| / - \`, whole seconds), erased before anything else is printed.

**Architecture:** Each shell file gets three small functions: `_how_to_spin_frame` (formats one frame), `_how_to_spin_on` (the enabled check), and `_how_to_spin` (the loop). The provider call is wrapped as `{ raw=$(… 3>&-); rc=$? } 3> >(_how_to_spin)`. The spinner reads a pipe nobody writes to, draws on each 0.1 s timeout, and exits silently at EOF. After it exits, the parent erases the line with `\r\e[K`.

**Tech Stack:** zsh (`zsh/system` for `sysread`), bash ≥ 4.4, `expect` for pty tests (optional, skipped if missing).

**Spec:** `docs/superpowers/specs/2026-10-11-spinner-design.md`

## Global Constraints

- Frame bytes exactly: `\r<c> thinking <n>s\e[K`, `<c>` = `|`, `/`, `-`, `\` for tick mod 4 = 0..3, `<n>` = whole seconds since the spinner started (truncated, starts at 0). Erase bytes exactly: `\r\e[K`.
- The first frame is drawn after the first 0.1 s timeout, not before (a provider that answers in < 0.1 s draws nothing).
- `HOW_TO_SPINNER` default `1`, set only if unset (zsh `(( ${+HOW_TO_SPINNER} )) ||`, bash `declare -p HOW_TO_SPINNER &>/dev/null ||`). Enabled iff `${HOW_TO_SPINNER-1}` ≠ `0` **and** `${TERM-}` ≠ `dumb` **and** `-t 2`, checked in that order.
- The spinner never writes after EOF, never reads the terminal, keeps SIGINT's default action, and writes only to stderr.
- The provider runs with `3>&-`.
- The parent erases only after the spinner has exited, and before the `rc` check (so before every later message, push or DSR query).
- zsh conventions: `emulate -L zsh` first line; externals via `command`. bash conventions: `local -` first line; code works under `set -euo pipefail`, `failglob`, `nocasematch`, odd `IFS`. See `CLAUDE.md`.
- Frame and erase output identical between the two files (tested from bash against zsh).
- Run bash tests with `/opt/homebrew/bin/bash src/test.bash` (macOS `/bin/bash` is 3.2).
- Elapsed time is computed as `SECONDS - start` with `start` taken when the spinner starts; nothing assigns `SECONDS` (equivalent to the spec's `SECONDS=0`, and immune to a user's `typeset -F SECONDS`).
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **bash, user has a background job** (`sleep 30 &` earlier, so `$!` is set): if process substitution doesn't set `$!` (bash < 5.x?), `wait $!` would block on the user's job. Expect: `how-to` returns promptly. Guard: remember `${!-}` before the block and `wait` only if it changed. Test in Task 2.
2. **bash, spinner subshell under hostile user options** (`set -euo pipefail`, `failglob`, `nocasematch`, `IFS=:`): `read -t` returning 142 on timeout must not trip `set -e` and kill the spinner after one frame. Expect: frames keep coming. pty mode `strict` in Task 2.
3. **zsh, `typeset -F SECONDS` or `setopt ksharrays` in the user's shell**: expect `| thinking 2s`, not `2.71s` or a wrong frame character. Tests in Task 1.
4. **bash `set -u` with `HOW_TO_SPINNER` or `TERM` unset**: expect no `unbound variable` error, and unset `HOW_TO_SPINNER` counts as on. Test in Task 2.
5. **Provider answers in < 0.1 s**: expect no frame to flash. pty mode `fast` in Tasks 1 and 2.

- [ ] **Step 2: Write the pty tests** (extend `pty.exp` and `pty()` in `src/test.bash`)

Add modes with the same semantics as the Task 1 table. In bash the command arrives through the DSR flow: after the spinner checks, `want "\033\[5n"`, `send "\033\[0n"`, `want "P> "`, `send "\r"`, `want $marker`. `pty()` gains a sleep argument, written to `$tmp/pty_sleep` instead of the hardcoded `typeahead` case; keep `typeahead` at 0.5. Modes:

- `spin`: sleep 1.3. Erase regex `thinking 1s\033\[K\r\033\[K`, and the erase must come before `\033\[5n`.
- `off`: sleep 0.4. Covers the `HOW_TO_SPINNER=0` prefix, which reaches the call through the `_how_to_pre` snapshot.
- `dumb`: sleep 0.4. Send `TERM=dumb` as its own line first, because a prefix only reaches `_how_to_pre`.
- `ctrlc-spin`: sleep 3. Its name avoids clashing with the existing `ctrlc` mode. Also check `echo GLOB-…` → `GLOB-ON`, as the `nounset` mode does.
- `fail`: sleep 0.4, stub output `HOWTO_FAIL: nope`. No DSR exchange happens in this mode.
- `fast`: sleep 0.
- `strict`: sleep 1.3. First send `set -euo pipefail; shopt -s failglob nocasematch; IFS=:`, then `how-to x`. Must see `thinking 0s` **and** `thinking 1s`, which proves the spinner survived its own read timeouts under `set -e`. Finish with the DSR exchange.

Each mode gets one `assert_eq "pty: …" PTY-OK …` line, named as in Task 1, plus `pty: spinner survives strict options`. All existing pty tests must keep passing. They now see frames whenever their stub sleeps, and they're expected to ignore them.
